# Resume and application safety

- Every candidate claim must trace to `profile/candidate-facts.md` or the selected master resume version.
- New master resumes create immutable versions. Existing tailored documents remain bound to their original version.
- Present proposed changes in Codex before generating a DOCX/PDF. Preserve the source layout and visually inspect the PDF.
- Chinese posting means Chinese resume; English posting means English resume; mixed posting requires user choice.
- Browser assistance is limited to job discovery and reading public job information. Do not fill fields, select options, upload files, log in, create accounts, or submit application forms.
- Provide the user with confirmed application materials and, when useful, a manual-entry checklist. Never inspect stored passwords or cookies.
